## 🧩 About

**ARK Survival Companion** is a curated list of ARK Survival open-source tools:

- **Overlays** — on-screen helpers, layout notes, resource tracker, stat viewer
- **Quality-of-Life Helpers** — tame catalog, crafting notes, base layout planner
- **Research Notes** — map layouts and config notes for educational use

Based on publicly available community tools and overlay helpers.

---

## ✨ Features

### ESP
- Stat Viewer — review health, stamina, and weight at a glance
- Resource Tracker — map nearby nodes for study
- Tame Notes — record and review taming progress
- Day Cycle Notes — track time of day for planning

### Wallhack
- Item Catalog — browse items, blueprints, and structures
- Skin Notes — organize survivor cosmetics
- Dino Reference — compare creature stats and diets

### Aimbot
- Base Planner Notes — segment study on any map
- Crafting Calculator — plan material requirements
- Loot Map Notes — mark supply drops and caves in the editor
